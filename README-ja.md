# Starlight Mayhem — HTML5 プレビュー

## 起動方法

1. ZIPを展開します。
2. 展開したフォルダー（`index.html` と `serve.py` がある場所）で、次を実行します。

   ```bash
   python3 serve.py
   ```

   Windowsでは `py serve.py` でも起動できます。初期設定は自分のPC内（`127.0.0.1:8080`）だけで待ち受けます。別ポートを使う場合は `python3 serve.py --port 8081` のように指定してください。

3. ブラウザーで <http://127.0.0.1:8080> を開きます。

このサーバーは画像・音声などの複数リクエストを並行処理し、遅い接続も長めに待ちます。まずはこの方法で起動してください。`index.html` を `file://` で直接開くのは避けてください。ブラウザーの音声再生制限により、初回は画面をクリックしてから操作が必要な場合があります。

## 操作

- **矢印キー／WASD**：メニュー移動・譜面入力
- **Enter**：決定
- **Esc**：戻る
- **スマートフォン**：横向き推奨。画面幅を4本の縦列に分け、左から **左・下・上・右** の順にタップして方向操作。右上で決定・戻る
- **R**：スコアリセット（対応画面）

## このプレビューについて

- ブラウザー用にキーボード入力、週一覧の読み込み、音声アセット（MP3）を調整しています。メインメニューBGMと操作音は、公式の **Starlight Mayhem: Rebooted 2.0.1** 配布版に収録されたOGG/WAV音源からWeb用MP3へ再生成しています。
- カスタム曲で通常曲用のステージIDがCJ素材の読み込み先を上書きしていた問題を修正しています。Chromiumで **Inverted Ascension** と **Artificial Lust** のプレイ中背景を確認済みです。
- Preferences画面で存在しないテキスト配列要素を参照してクラッシュする問題も修正しています。設定画面を開き、全項目を移動するテストをしています。
- スマートフォン向けに画面幅全体を4本の縦レーンに分割し、左から左・下・上・右の色分け入力を配置しています。画面全体の4色枠も表示します。操作UIの塗り・発光はスマートフォンだけ控えめにしています。
- モバイルでStory Modeを開始した際の負荷を抑えつつCJ・BFたちを表示するため、Storyメニュー用Atlasの半解像度版を使います（RGBA展開時の目安は約416 MiBから約104 MiB）。スマートフォンではこの人物アニメだけ12 fpsにしてCPU負荷も抑え、PC版は元解像度・元の動作を維持します。
- 起動時にOSを判定し、URLへ `?platform=Windows`、`?platform=Android` などを付けます。ゲーム側からは `window.gamePlatform`（例：`"Windows"`）または `window.isWindowsPC` で判定できます。`?platform=Windows` を付けて開けば手動指定もできます。
- Chromiumでタイトル、Story Mode、Freeplay、およびFreeplayからの譜面開始をスモークテスト済みです。
- 全曲、全難易度、すべてのカットシーン／ブラウザー環境を網羅的にテストしたものではありません。
